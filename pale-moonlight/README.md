# Pale Moonlight — Chapter 1

A real ScummVM / SLUDGE adventure. Only Chapter 1 is playable.

Click to walk. Choose a verb and click an object. Right-click examines. F1 hints, F5 save, F7 load.

Scene editing and in-game placement editing have been removed completely.

Build with Python, Pillow and sludge-compiler: python tools/build.py.

The browser loader uses ScummVM WebAssembly and its SLUDGE plugin. Runtime source: https://github.com/scummvm/scummvm and https://github.com/chkuendig/scummvm-demo (GPL-3.0-or-later).
